# Type Beat

## Idea
An electric typographic poster: MAKE / IT MOVE stays readable while individual
letters bounce and brighten like a traveling rhythm. A smaller BEAT LOCKED
signature alternates its emphasis one word per hit.

## Rhythm
120 BPM, 4 bars of 4/4. Main letters stagger by an eighth beat over quarter-note
pattern [1, 0, .45, 0]. A softer hit answers the first; rests let tails finish.
The signature selects one of two words on each half-note hit, four rounds per loop.

## Look
Near-black navy, oversized warm ivory letters with acid yellow accents. Main
text in a centred box with generous margins. Keep base opacity high enough to
read the complete phrase at phone size between accents. Scale down on the hit
and lift very slightly, reserving space inside the box. Two canvases retain the
same hierarchy and all text remains inside its box.

## Assets
Read collections/test/manifest.json: test/BBH Bogle, a heavy condensed display
face, one static 400 normal face, complete printable ASCII, no variable axes.
No clips. Axis animation is verified with Lab Block in generated fixtures only;
this machine has no real variable font collection.

## Notes
Explicit line breaks; no automatic wrapping or registry layer. Text and rhythm
are Studio props. Generated letters stay procedural, edited through those props.
